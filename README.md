# Campus Quest

Full-stack gamified college learning and peer-support app: streaks, XP, badges, weekly leaderboard, interactive chapter quizzes, and a Study Help forum with accept-and-celebrate rewards.

## Run locally

```bash
npm run dev
```

- API: http://localhost:4000
- App: http://localhost:5173
